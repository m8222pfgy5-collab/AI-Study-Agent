## Features

- AI-powered study task management
- Class schedule uploads (images, PDFs, CSV)
- Automatic study plan generation
- Deadline tracking
- Persistent task storage
- Chinese and English interface

## Technologies

Python, Streamlit, OpenAI Agents SDK, JSON

## How to Run

1. Install the required Python packages:

   `pip install -r requirements.txt`

2. Create a `.env` file and configure `OPENAI_API_KEY`.

3. Start the application:

   `streamlit run web_app.py`

4. Open `http://localhost:8501` in your browser.

## About

This project was developed to help university students organize their classes, manage assignments, and plan study time more efficiently.
